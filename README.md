# Dead Pixels — Rebirth

Браузерный 2D roguelite-платформер, вдохновлённый динамичными экшен-играми в духе Dead Cells.

Проект работает без игрового движка: рендеринг выполнен на HTML5 Canvas, звук генерируется через Web Audio API, а прогресс и настройки сохраняются в LocalStorage.

## Возможности

- процедурно оформленные уровни и биомы;
- ближний и дальний бой;
- комбо, перекаты, парирование и способности;
- противники, элитные враги и боссы;
- частицы, освещение, экранные эффекты и анимации;
- процедурно генерируемые музыка и звуковые эффекты;
- магазин, улучшения и несколько слотов сохранения;
- управление с клавиатуры и сенсорных устройств.

## Запуск

Проект не требует сборки.

### Самый простой способ

Откройте `index.html` в современном браузере.

### Рекомендуемый способ

Запустите локальный HTTP-сервер из папки проекта:

```bash
python -m http.server 8080
```

Затем откройте в браузере:

```text
http://localhost:8080
```

Также можно использовать любой другой статический сервер, например `npx serve`.

## Структура проекта

Сейчас основная версия игры находится в `index.html`. В следующих этапах разработки код планируется постепенно разделить на независимые модули: игровой цикл, ввод, звук, сущности, генерацию мира, интерфейс и рендеринг.

## Разработка

Перед отправкой изменений рекомендуется проверить встроенный JavaScript:

```bash
python scripts/check-inline-js.py
```

GitHub Actions выполняет эту проверку автоматически для pull request и изменений в основной ветке.
